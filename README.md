# CBN-Inflation-Data-Analysis
# **Project Overview**

This Project aims to analyse monthly Nigerian inflation data obtained from the Central Bank of Nigeria (CBN) using Microsoft Excel. The project is part of my practical learning journey in data analytics, with a focus on data preparation, Pivot Tables, and data interpretation.

# **Objective**

The objective of this project is to develop practical Excel data analysis skills by preparing economic data, creating Pivot Tables, and identifying meaningful insights from inflation trends.

# **Dataset**

The dataset contains monthly inflation indicators, including headline inflation, food inflation, and inflation measures excluding farm produce and energy.
**Source**: Central Bank of Nigeria (CBN)

# **Data Preparation**

The data preparation phase involved:
1. Importing the CBN inflation dataset into Excel.
2. Converting the inflation values to percentage format.
3. Converting the year,month and period fields into appropriate data types.
4. Renaming technical column headers to more meaningful names.
5. Converting the data range into an Excel Table named "InflationData".

# **Pivot Table Analysis**
Three Pivot Tables were created to answer specific questions about the inflation data.

1. **Annual Headline Inflation**

   **Question:** How has Nigerian Headline Inflation Changed overtime?

   A pivot table was created to calculate the average headline inflation rate for each year.
   **Key findings:**
- The lowest annual average in the dataset was **5.42% in 2007**.
- The highest annual average was **33.18% in 2024**.
- Average headline inflation increased from **18.77% in 2022** to **33.18% in 2024**, before declining to **23.39% in 2025**.
- The 2026 figure represents January to August and therefore does not represent a complete year.

2. **Food Inflation vs. Headline Inflation**

**Question:** How does food inflation compare with headline inflation across different years?

A Pivot Table was created to compare the average annual headline inflation rate with the average annual food inflation rate.

**Key findings:**
- Food inflation exceeded headline inflation in several recent years.
- In 2024, food inflation averaged **39.10%**, compared with **33.18%** for headline inflation.
- The difference between food and headline inflation in 2024 was **5.92 percentage points**.
- In 2025, food inflation was **22.32%**, slightly below headline inflation at **23.39%**.

3. **Monthly Headline Inflation**

**Question:** Which months have historically recorded higher average headline inflation?

A Pivot Table was created to calculate the average headline inflation rate for each calendar month across the dataset.

**Key findings:**
- **October** recorded the highest historical monthly average at **14.75%**.
- **January** recorded the lowest at **14.24%**.
- The difference between the highest and lowest monthly averages was **0.51 percentage points**.
- The relatively small difference indicates limited variation in historical average headline inflation across calendar months.

**Analysis Approach**

The analysis in this stage is primarily **descriptive**, using Pivot Tables to summarize historical inflation patterns. Comparative analysis was also used to examine differences between food and headline inflation.

The findings describe patterns in the dataset but do not by themselves establish the causes of changes in inflation.
