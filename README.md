# CBN-Inflation-Data-Analysis
**Project Overview**

This Project aims to analyse monthly Nigerian inflation data obtained from the Central Bank of Nigeria (CBN) using Microsoft Excel. The project is part of my practical learning journey in data analytics, with a focus on data preparation, Pivot Tables, and data interpretation.

**Objective**

The objective of this project is to develop practical Excel data analysis skills by preparing economic data, creating Pivot Tables, and identifying meaningful insights from inflation trends.

**Dataset**

The dataset contains monthly inflation indicators, including headline inflation, food inflation, and inflation measures excluding farm produce and energy.
**Source**: Central Bank of Nigeria (CBN)

**Data Preparation**

The data preparation phase involved:
1. Importing the CBN inflation dataset into Excel.
2. Converting the inflation values to percentage format.
3. Converting the year,month and period fields into appropriate data types.
4. Renaming technical column headers to more meaningful names.
5. Converting the data range into an Excel Table named InflationData.
